# 部署与验收

1. 解析项目、服务、环境和版本，不用名称猜 ID。
2. 备份将修改的配置或文件，定义回滚点。
3. 只部署已通过本地检查的精确提交或制品。
4. 控制面错误先回读状态再有限重试，禁止盲目重复发布。
5. 验证健康端点、单进程、依赖连接、关键业务路径和持久化。
6. 失败则回滚并复验；成功则记录版本和验证证据。

生产写入、用户数据、权限和资金相关动作不得省略安全门禁。
